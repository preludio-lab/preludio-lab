# 作曲家管理画面 (Composer Admin) 詳細仕様

本ドキュメントは、`docs/05_design/05_admin/admin-ui-design.md` の大枠のレイアウト設計に基づき、**作曲家管理画面に特化したデータ表示・アクションの仕様**を定義します。

## 1. 共通仕様 (Common)

### 多言語対応 (I18n)

- 画面左側のサイドバーで選択された言語に基づき、各データレコードの多言語対応フィールド（例: `displayName`, `fullName`）を出し分けます。
  - ここでいう言語選択とは、マスターデータ（管理画面内の表のデータ）の表示言語のことです。
  - データの表示言語選択にURLパスの `[lang]` は用いません。URLパスの `[lang]` はページ全体の言語設定に使用します。
- 当該言語での登録がない場合は、フォールバックとして日本語（`ja`）を優先して表示し、それでもない場合は「Unknown」またはそのままのオブジェクト情報を利用可能な範囲で表示します。

---

## 2. 作曲家一覧画面 (List View)

一覧画面では、**認知しやすさ（一瞥性）と運用上の必要性**を重視し、ノイズとなる情報を削ぎ落として構成します。

### 2.1 カラム定義

| カラム名                    | データソース        | 仕様・表示ロジック                                           | 備考                                                     |
| --------------------------- | ------------------- | ------------------------------------------------------------ | -------------------------------------------------------- |
| **画像 (Portrait)**         | `portrait`          | 円形のサムネイル画像を配置                                   | 画像がない場合は名称の頭文字をプレースホルダーとして表示 |
| **名前 (Name)**             | `displayName`       | 選択言語での名称を表示                                       |                                                          |
| **Slug**                    | `slug`              |                                                              |                                                          |
| **時代 (Era)**              | `era`               |                                                              |                                                          |
| **国籍 (Nationality)**      | `nationalityCode`   | 国籍（ISOコード）を表示                                      |                                                          |
| **最終更新 (Last Updated)** | `control.updatedAt` | YYYY/MM/DD HH:mm 形式（選択言語のロケールに基づく）          | `createdAt` よりも運用の実態に即しているため採用         |
| **アクション (Actions)**    | -                   | ・詳細画面 (`/[lang]/admin/composers/[slug]`) への遷移ボタン |                                                          |

### 2.2 デザイン・UXの方針

- `createdAt` を一覧に表示しないことで、列の圧迫を回避します。
- レコードをクリック、またはアクションカラムのアイコンクリックで詳細画面へ遷移します。

---

## 3. 作曲家詳細・編集画面 (Detail & Edit View)

詳細画面では、**情報の網羅性と編集のしやすさ**を重視し、Z型/F型の視線誘導に合わせて情報を配置します。

### 3.1 画面レイアウト構成

詳細画面は大きく**メインカラム (2/3幅)** と **サイドバー領域 (1/3幅)** に分割します。

#### ヘッダー領域

- **Portrait**: 大きめの円形あるいは角丸画像
- **DisplayName / Slug**: 選択中の言語による名称表示と、不変のSlug情報

#### メインカラム (左側)

- **基本情報**:
  - `displayName` (多言語入力対応フィールド)
  - `fullName` (多言語入力対応フィールド)
  - `era` (時代区分)
  - `nationalityCode` (国籍)
- **関連データ**:
  - `representativeInstruments` (代表的な楽器)
  - `representativeGenres` (代表的なジャンル)
  - `tags` (自由タグ)
  - `impressionDimensions` (印象評価次元 - スライダー等で編集)

#### サイドバー領域 (右側) - メタ・システム情報

- **ステータス・更新情報**:
  - `createdAt` (作成日時)
  - `updatedAt` (最終更新日時)
- **アクション**:
  - `保存 (Save)`
  - `削除 (Delete - Danger Action)`
- **リレーション表示**:
  - 「関連作品 (Works)」の一覧へのリンク、またはプレビュー表示エリア

### 3.2 編集時の動作

- 入力フォームの各言語別フィールドはタブなどで切り替え可能にするか、言語選択ドロップダウンに応じて表示を切り替えます。
- 変更があった場合は「保存」ボタンをアクティブにし、未保存での離脱時に警告を出します (`Warning` カラーの活用)。
