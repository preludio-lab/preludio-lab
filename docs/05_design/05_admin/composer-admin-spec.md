# 作曲家管理画面 (Composer Admin) 詳細仕様

本ドキュメントは、`docs/05_design/05_admin/admin-ui-design.md` の大枠のレイアウト設計に基づき、**作曲家管理画面に特化したデータ表示・アクションの仕様**を定義します。

## 1. 共通仕様 (Common)

### 多言語対応 (I18n)

- 画面左側のサイドバーで選択された言語に基づき、各データレコードの多言語対応フィールド（例: `displayName`, `fullName`）を出し分けます。
  - ここでいう言語選択とは、マスターデータ（管理画面内の表のデータ）の表示言語のことです。
  - データの表示言語選択にURLパスの `[lang]` は用いません。URLパスの `[lang]` はページ全体の言語設定に使用します。
- 当該言語での登録がない場合は、フォールバックとして日本語（`ja`）を優先して表示し、それでもない場合は「Unknown」またはそのままのオブジェクト情報を利用可能な範囲で表示します。

## 2. 作曲家一覧画面 (List View)

一覧画面では、**認知しやすさ（一瞥性）と運用上の必要性**を重視し、ノイズとなる情報を削ぎ落として構成します。

### 2.1 カラム定義

| カラム名                    | データソース        | 仕様・表示ロジック                                           | 備考                                                     |
| --------------------------- | ------------------- | ------------------------------------------------------------ | -------------------------------------------------------- |
| **画像 (Portrait)**         | `portrait`          | 円形のサムネイル画像を配置                                   | 画像がない場合は名称の頭文字をプレースホルダーとして表示 |
| **名前 (Name)**             | `displayName`       | 選択言語での名称を表示                                       |                                                          |
| **Slug**                    | `slug`              |                                                              |                                                          |
| **時代 (Era)**              | `era`               |                                                              |                                                          |
| **国籍 (Nationality)**      | `nationalityCode`   | 国籍（ISOコード）を表示                                      |                                                          |
| **最終更新 (Last Updated)** | `control.updatedAt` | YYYY/MM/DD HH:mm 形式（選択言語のロケールに基づく）          | `createdAt` よりも運用の実態に即しているため採用         |
| **アクション (Actions)**    | -                   | ・詳細画面 (`/[lang]/admin/composers/[slug]`) への遷移ボタン |                                                          |

### 2.2 デザイン・UXの方針

- `createdAt` を一覧に表示しないことで、列の圧迫を回避します。
- レコードをクリック、またはアクションカラムのアイコンクリックで詳細画面へ遷移します。

---

## 3. 作曲家詳細・編集画面 (Detail & Edit View)

詳細画面では、**情報の網羅性と編集のしやすさ**を重視し、Z型/F型の視線誘導に合わせて情報を配置します。

### 3.1 画面全体の構造

画面は上から、**ナビゲーション領域**、**ヘッダー領域**、**タブコンテンツ領域**の3層で構成します。

#### ナビゲーション領域

- **「一覧に戻る」ボタン**: 作曲家一覧画面 (`/[lang]/admin/composers`) へのリンク。左矢印アイコン + テキストの構成で、画面最上部に固定配置します。

#### ヘッダー領域

- **Portrait**: 円形の肖像画像（画像がない場合は表示名の頭文字をプレースホルダーとして表示）
- **DisplayName**: 大きめのタイトル (`h1`) として表示
- **FullName**: DisplayNameと異なる場合にサブタイトルとして表示
- **Slug**: モノスペースフォントで薄色表示
- **パンくず**: 「管理画面 / 作曲家管理 / {DisplayName}」形式で表示
- **モード切替ボタン** (右寄せ):
  - **閲覧モード時**: 「編集」ボタン（ペンアイコン付き）を表示
  - **編集モード時**: 「編集」ボタンは非表示（フォーム内の「保存」「キャンセル」ボタンに委譲）

#### タブ構成

| タブID  | タブ名   | 内容                                                          |
| :------ | :------- | :------------------------------------------------------------ |
| `basic` | 基本情報 | メインカラム (2/3幅) + サイドバー (1/3幅) の2カラムレイアウト |
| `works` | 関連作品 | 関連作品テーブル                                              |

### 3.2 「基本情報」タブの構成

#### メインカラム (左側、2/3幅)

以下の各セクションはカード形式 (`bg-admin-card-bg`, `border`, `rounded-lg`) で区切ります。

| セクション名            | フィールド                                                  | 表示形式                                                                                                            |
| :---------------------- | :---------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| **共通情報**            | `era`, `nationalityCode`, `birthDate`, `deathDate`          | 2列グリッドでラベル+値表示                                                                                          |
| **名称情報** (選択言語) | `fullName`, `displayName`, `shortName`                      | 2列グリッドでラベル+値表示                                                                                          |
| **要約 (Summary)**      | `summary`                                                   | 複数行テキスト表示 (`whitespace-pre-wrap`)                                                                          |
| **音楽的特徴**          | `representativeInstruments`, `representativeGenres`, `tags` | タグバッジ (pill形式) で横並び表示。未設定時は「未設定」テキスト                                                    |
| **活動拠点**            | `places` (slug, type, countryCode)                          | リスト形式。各拠点にタイプラベル (生誕地/没地/活動地) と国コードを併記。データなしの場合はセクション非表示          |
| **印象次元**            | `impressionDimensions` (6軸)                                | 中央基準バーチャート (-10 to +10)。各軸にラベル名・両端の極性ラベル・数値を表示。データなしの場合はセクション非表示 |

**印象次元バーチャートの仕様:**

- バーの中央が0を表し、正方向（右）と負方向（左）に伸びるデザイン
- 各軸に対応する日本語の両端ラベル（例: 革新性 = 「伝統的 <-> 革新的」）を表示
- 数値を符号付き（`+6`, `-3`）でバー右端に表示

#### サイドバー領域 (右側、1/3幅)

| セクション名     | フィールド               | 表示形式                                                  |
| :--------------- | :----------------------- | :-------------------------------------------------------- |
| **ステータス**   | `createdAt`, `updatedAt` | `YYYY/MM/DD HH:mm` 形式（ロケール準拠）                   |
| **システム情報** | `id` (UUID), `slug`      | モノスペースフォントで表示。UUIDは `break-all` で折り返し |

### 3.3 編集モードの動作

- **トリガー**: ヘッダー領域の「編集」ボタンをクリックで編集モードに遷移
- **編集モード時の表示**:
  - ヘッダー領域: 「編集」ボタンが非表示になる。ヘッダータイトルに「(編集)」の接尾辞が追加される
  - ContentArea: タブUIが非表示になり、`ComposerEditForm` コンポーネントが全幅で表示される
  - ナビゲーション（一覧に戻るボタン）は編集時も維持
- **フォーム内のアクションボタン** (フォームのフッター):
  - **「キャンセル」ボタン**: 変更を破棄し、閲覧モードに復帰
  - **「変更を保存」ボタン**: `updateComposerAction` を実行し、成功時にページリロード
  - 処理中は両ボタンが無効化 (`disabled`) される
- **言語別入力**: 入力フォーム内に言語タブ (JA, EN, ES, DE, FR, IT, ZH) を配置し、選択言語に応じてフィールドを切り替え
- **将来拡張**:
  - 変更がある状態でのページ離脱時に警告を出す (`Warning` カラーの活用)
  - `削除 (Delete)` アクションの追加 (Danger Action)
