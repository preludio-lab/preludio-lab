# 音楽メタデータのスラグ命名規則

このドキュメントでは、AI生成コンテンツおよび手動入力間の一貫性を確保するため、作品とその構成要素（楽章など）の命名規則を定義します。エージェントが自律的に一貫したスラグを生成できるよう、曖昧さを排除しアルゴリズム化された規則に従います。

## 1. 作品スラグ (`work-slug`)

`work-slug` は、作曲家ディレクトリ内での作品の一意の識別子です。楽曲を以下の2つのパターンに分類し、フォーマットを固定します。

### パターンA: 形式・ジャンル主体の楽曲 (Generic Works)

交響曲、ソナタ、協奏曲、弦楽四重奏曲など。

- **フォーマット**: `[genre]-[index]` または `[genre]`
- **インデックスの要否 (最優先)**: 同カテゴリ（ジャンル）の楽曲が作曲家内で合計1曲しか存在しない場合、インデックスを省略し `[genre]` のみとします。
  - 例: `piano-sonata` (リストのピアノソナタは1曲のみのため)
- **インデックスの優先順位**: 重複がある場合、以下の優先順位で最初に該当するものだけを採用します。
  1. **通し番号 (Serial Number)**: `no-[数字]` (例: `symphony-no-5`)
  2. **カタログ番号 / 作品番号 (Catalog / Opus)**: `[prefix]-[数字]` (例: `op-9-2`, `bwv-846`)
  3. **調性 (Key)**: `[note]-[major|minor]` (上記1, 2がない場合のみ)

### パターンB: 固有のタイトルを持つ楽曲 (Unique Works)

オペラ、バレエ音楽、交響詩、歌曲など。

- **フォーマット**: `[title]` (kebab-case)
- **例**: `eine-kleine-nachtmusik`, `mastersingers-of-nuremberg`

### 共通ルール

- **形式**: `kebab-case`（小文字、ハイフン区切り）。
- **言語**: 英語タイトル（または翻字）を使用。
- **ドットの禁止**: 作品番号などのドット（`.`）はハイフンに置き換えるか、明確な場合は省略します。
- **ストップワードの排除**: `the`, `a`, `in`, `of` などの単語は原則として除外します。
- **愛称 (Nicknames) の排除**: 「運命」「月光」などの愛称はスラグに含めず、メタデータとして保持します。ただし、楽曲自体を指すタイトル（例: `symphonie-fantastique`）はパターンBとして扱います。

### タクソノミーの準拠 (Enum)

エージェントは以下の値を [`docs/01_specs/taxonomy.yaml`](file:///docs/01_specs/taxonomy.yaml) から選択しなければなりません。表記揺れを防ぐため、独自にジャンルを命名することは禁止です。

- **ジャンル**: `genres` セクションの `id` を使用（例: `symphony`, `piano-sonata`, `violin-sonata`, `string-quartet` 等）。
- **カタログプレフィックス**: `catalogue_prefixes` の `id` を使用（例: `op`, `bwv`, `k`, `hob-i`）。`kv` ではなく `k` を使用。
- **調性**: `keys` の `id` を使用（例: `c-major`, `g-minor`）。

## 2. 楽章・曲目スラグ (`work-part-slug`)

`work-part-slug` は、作品の構造的要素（楽章、変奏など）の一意の識別子です。

- **形式**: `[プレフィックス]-[インデックス]` または `[役割]`。
- **プレフィックス**:
  - `mov`: 楽章 (例: `mov-1`, `mov-2`)
  - `var`: 変奏 (例: `var-theme`, `var-1`)
  - `no`: 小曲・番号 (例: `no-1`, `no-2`)
  - `act`: 幕 (例: `act-1`)
  - `scene`: 場 (例: `scene-1`)
- **役割ベースのスラグ**: 一般的な名称の場合、プレフィックスを省略可能です。
  - `overture`: 序曲
  - `prelude`: 前奏曲
  - `finale`: 終曲
  - `cadenza`: カデンツァ
  - `intro`: 導入部
- **意味を持つ単語の禁止**: スラグに速度記号（Allegro等）や固有のタイトルを含めないでください。
- **正規化**: 数字は常にアラビア数字（`1, 2, 3...`）を使用し、ローマ数字は使用しないでください。
