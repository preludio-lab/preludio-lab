# AI Agent Workflows 仕様書

## 概要

AIエージェント、Coreモジュール、およびTools群を組み合わせて、一連のタスクやビジネスロジックを実行するためのスクリプト群を配置するディレクトリです。エージェントが主体となって業務プロセスを完遂するためのフロー定義が含まれます。

## 目的

1. エージェントやツールの単体操作だけでなく、それらを数珠つなぎにした「複合的なタスクプロセス（ワークフロー）」を定義する。
2. AIエージェントを利用した自動化スクリプトの実行手順をコードとして明文化し、結果の再現性を確保する。
3. エージェントの動作検証や、今後のバッチ処理基盤への拡張を容易にする。

## 実装方針

- **関心の分離**: 1つのワークフローは1つの目的（例：テスト実行、特定データの収集パイプライン）に絞り、複雑化を防ぐ。
- **実行状態とエラー管理**: ワークフロー全体でのエラーハンドリングを徹底し、途中失敗時にも安全に再実行できる（冪等性の担保）設計を心がける。
- **状態の永続化 (State Management)**: インフラ実行環境（ローカルCLIやGitHub Actions等）のステートレス性を考慮し、処理の進捗や状態をローカルファイル（`agents/state/` 等のJSON）にチェックポイントとして適宜書き出す。再起動時にその状態を読み込んで安全に処理を再開できるアーキテクチャを標準とする。
- **テストの兼任**: `test-core.ts` のようなモジュール動作検証用フローもここに含め、将来的に自動テスト（CI）組み込みができるよう実装する。
