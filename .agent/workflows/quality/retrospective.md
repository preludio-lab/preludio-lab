このワークフローは、AIエージェントとのセッション完了時に実施する「振り返り（レトロスペクティブ）」です。
今回の作業を通じて得られた知見、うまくいった点、改善すべき点を言語化し、次回の開発品質と効率を向上させることを目的とします。

以下のフォーマットに従って、今回のセッションを振り返ってください。

# セッション振り返り (Retrospective)

## 1. 概要 (Summary)

- **タスク:** [今回のタスク内容を簡潔に]
- **結果:** [完了/未完了/一部完了]
- **主な成果物:** [変更したファイル、作成したドキュメントなど]

## 2. KPT (Keep / Problem / Try)

### Keep (良かったこと・続けたいこと)

- [ ] エージェントの振る舞いで助かったこと
- [ ] 効果的だった指示（プロンプト）の仕方
- [ ] 採用して良かった設計や実装パターン

### Problem (課題・うまくいかなかったこと)

- [ ] 手戻りが発生した箇所とその原因
- [ ] エージェントへの指示がうまく伝わらなかった場面
- [ ] 実装上の技術的なハマりポイント

### Try (次回の改善・挑戦したいこと)

- [ ] 次回のエージェントへの指示の改善案
- [ ] ルールファイル (`.agent/rules/*.md`) への追記・修正案
- [ ] ワークフロー (`.agent/workflows/*.md`) の改善案
- [ ] 新たに導入したいツールやライブラリ

## 3. アクションアイテム (Action Items)

- [ ] ルールファイルの更新 (必要な場合)
- [ ] ドキュメントの更新 (必要な場合)
- [ ] 次のタスクへの引き継ぎ事項

---

**エージェントへの指示:**
この振り返り内容をもとに、もし `.agent/rules/` や `.agent/workflows/` の更新が必要な場合は、具体的な修正案を提案してください。
