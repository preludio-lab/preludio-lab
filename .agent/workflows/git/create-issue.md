GitHub Issueを登録して

以下の手順で実施:

1. `.github/ISSUE_TEMPLATE/ai_issue_report.md` のテンプレートに従ってIssue内容を作成
2. `gh issue create` コマンドを使用してGitHubに登録
3. Issue作成以外のタスク（修正作業など）には着手しないこと

注意:

- タイトルは `[AI]` プレフィックスを付けること
- ラベルは `bug` を使用（`ai-reported` は存在しない場合がある）
- Issue本文は必ずテンプレートの全セクションを埋めること
