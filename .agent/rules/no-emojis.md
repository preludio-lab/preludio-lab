# 絵文字（Emoji）等の特殊記号の非推奨・使用禁止

生成AI特有の出力として、Markdownドキュメント、ソースコード内のコメント、コミットメッセージ、スクリプトのログ出力などに **絵文字（例: ❌, ✅, ⚠️, 🚀 など）や、その他不要な特殊記号** を使用することを**固く禁じます**。

## 理由

- **文字化けリスク**: CI環境やログパーサー、異なるターミナルエミュレータにおいて文字化けの原因となり、システムの堅牢性を損ないます。
- **可読性とノイズ**: エンタープライズレベルの最高品質のアプリケーションソースコードおよびドキュメントにおいて、装飾的な記号はノイズとなり不適切です。
- **検索性の低下**: `grep` 等によるログ調査やテキスト検索の妨げになります。

## ルール

- ドキュメント内の「良い例・悪い例」を示す際は、単に `Bad` や `Good` と記述し、修飾記号を付けないでください。
- いかなるシチュエーションにおいても、成果物（ユーザー提供ファイル）に絵文字を意図的に混入させないでください。
